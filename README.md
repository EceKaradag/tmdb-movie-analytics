# TMDb Movie Analytics

This project analyzes movie data from The Movie Database (TMDb) to explore what drives movie performance and audience engagement. The analysis was completed as part of a team project, using Python to clean, explore, and visualize a real-world dataset.

The goal is to understand patterns in genres, popularity, and other features that may influence how movies perform.

## Objectives
- Explore trends in movie genres and popularity
- Identify patterns in audience engagement
- Practice real-world data cleaning and exploratory analysis
- Communicate insights through visualizations

## Tools Used
- Python
- Pandas
- Matplotlib / Seaborn
- Jupyter Notebook

## Dataset
The dataset contains movie-level information such as:
- Titles and release details
- Genres
- Popularity metrics
- Ratings and other attributes

## Key Highlights
- Genre-level patterns in popularity and performance
- Visual comparisons across movie categories
- Structured exploratory data analysis in a team setting
